# Blinkit-Power-Bi-Dashboard-and-SQL-analysis

## Project Overview
This project analyzes grocery sales data to understand sales performance, product trends, and outlet-level performance. SQL was used for data cleaning, KPI calculations, and business analysis, while Power BI was used to build an interactive dashboard.

## Objectives
- Analyze overall sales performance.
- Compare sales across item types and fat-content categories.
- Evaluate outlet performance by location, size, type, and establishment year.
- Calculate key performance indicators (KPIs).
- Present business insights through interactive visualizations.

## Tools & Technologies
- **SQL:** Data cleaning, aggregation, KPI calculations, GROUP BY, and window functions.
- **Power BI:** Dashboard development and data visualization.
- **CSV/Excel:** Dataset storage and inspection.

## Key Analysis
- Total sales, average sales, number of items, and average rating.
- Sales by item type and fat content.
- Sales comparison across outlet locations and sizes.
- Outlet performance by establishment year and outlet type.
- Percentage contribution of outlet sizes and locations to total sales.

## Data Cleaning
Standardized inconsistent fat-content labels, including `reg` to `Regular` and `LF` / `low Fat` to `Low Fat`, to improve consistency in reporting.

## Project Files
- `Blinkit_Data_Analysis.sql` — SQL queries for data cleaning and analysis.
- `Blinkit-analysis.pbix` — Power BI dashboard.
- `BlinkIT-Grocery-Data.csv` — Source dataset, if permitted to redistribute.

## Skills Demonstrated
SQL, Data Cleaning, KPI Analysis, Business Intelligence, Data Aggregation, Window Functions, Power BI, and Data Visualization.

## Business Value
The analysis provides a structured view of sales across product categories and outlets, helping stakeholders explore performance patterns and support data-driven decisions.

## How to Explore
1. Download or clone this repository.
2. Open the SQL script in a compatible SQL environment after configuring the dataset and table.
3. Open the `.pbix` file in Power BI Desktop.
4. Connect the dashboard to the appropriate dataset if prompted.
